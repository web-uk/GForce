# Privacidade

O GForce é um site público para uso pessoal. Não possui cadastro nem servidor que armazene seus registros. Nome opcional, respostas do perfil, limitações, peso/medidas opcionais, calendário, sessões, disposição e notas ficam no IndexedDB deste contexto do navegador.

Não coletamos telemetria e não enviamos registros para terceiros. GitHub Pages entrega os arquivos estáticos e está sujeito à política de privacidade do GitHub e seus logs de acesso. Ao abrir uma referência externa, você visita outro site; vídeos e imagens externos não são carregados automaticamente no GForce.

A senha é um controle de acesso local. Somente salt e verificador derivado são armazenados. Ela não criptografa os registros e não torna o site privado. Uma pessoa com acesso técnico ao navegador pode ler ou alterar dados locais. Não use como cofre médico.

“Bloquear agora” pede a senha novamente. “Exigir senha a cada abertura” é opcional, inicialmente desativado. Outro aparelho, perfil de navegador ou instalação pode manter um conjunto independente de registros e senha. Não há sincronização silenciosa.

O backup JSON contém registros pessoais em texto, sem criptografia. Não inclui senha, verificador nem estado de desbloqueio. Guarde o arquivo de forma privada; nunca envie backups ao repositório. Exportar não garante que o arquivo foi guardado com segurança: confira o download.

Em Configurações, é possível exportar, restaurar com resumo e confirmação, ou excluir. A exclusão requer senha atual quando desbloqueada e a palavra APAGAR. Se esquecer a senha, a recuperação exige reinicialização e perda dos dados locais sem backup. A exclusão não alcança arquivos de backup já baixados ou dados em outros aparelhos.

Navegação privada, limpeza automática, falta de espaço e políticas do Safari podem apagar ou impedir persistência. Faça backup regularmente, principalmente antes de mudar de aparelho ou limpar o navegador. A data do último backup é um lembrete local, não prova de armazenamento externo.
